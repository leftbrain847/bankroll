# Moonhold

A property-trading board game for phones, set in a ring of moons. 2–6 players share one device (pass-and-play), and any seat can be a bot. It runs fully offline. Built on [app_builder](https://github.com/leftbrain847/app_builder) as a `solo` app, so the same build ships as a single page, a friends link and an offline Google Play bundle.

## Run
```
npm ci
npm run dev          # local dev server
npm run build:demo   # the whole game as one self-contained page: dist/demo/page.html
npm run build:play   # offline Play bundle, checked for network code
```

## Test
```
npm run typecheck && npm test
```
CI (`.github/workflows/app.yml`, generated by app_builder) runs typecheck, tests, the build and the Play no-network check.

## How it's built

| Path | What |
| --- | --- |
| `src/game/economy.ts` | **The one economy config.** Every price, fee, building cost, stipend, levy, fee and starting balance is generated from these constants. |
| `src/game/board.ts` | The 40-space loop: names, systems, colours, marks. |
| `src/game/cards.ts` | The Signal and Salvage decks (16 cards each). |
| `src/game/rules.ts` | The rules engine: `apply(state, player, action)`. Pure and seeded: no clock, no `Math.random`, no DOM. |
| `src/game/ai.ts` | Bots (buying, bidding, building, raising cash, trading). Tuning in `BOT`. |
| `src/client/` | The UI: orbit board (canvas), action panel, sheets, synthesized sound. |
| `test/rules.test.ts` | 52 tests: one or more for every rule below. |

## Standard mechanics (kept identical)

These follow the standard property-trading game rules; the names are Moonhold's:

- 40-space loop, numbered as on the standard board: four corners (Launch = collect stipend, Quarantine = jail / just visiting, Drift = free rest, Tractor Beam = go to Quarantine); 22 moons in 8 systems (two systems of two at the ends of sides 1 and 4, six of three); 4 gates (transit) mid-side; 2 works (utilities); 3 Salvage + 3 Signal draw spaces; 2 levies (taxes).
- 2d6 movement. Doubles roll again; a third double in one turn sends you to Quarantine.
- Quarantine: leave by paying the fee, using a Clearance Pass, or rolling doubles (move, no extra roll). After the third failed try, pay and move.
- Stipend for passing or landing on Launch.
- Buy unowned claims; a declined claim is auctioned to every player (the decliner too).
- A full system doubles base rent on its unbuilt moons, even if another moon in it is mortgaged.
- 4 domes then 1 spire, built evenly. The bank holds 32 domes and 12 spires; when they run out nobody can build, and a spire can only break into domes the bank has (otherwise the system is sold down at once). Buildings sell back at 50%.
- Mortgage at 50% of price; lift at mortgage + 10%; no rent while mortgaged; sell a system's buildings before mortgaging or trading any of its moons.
- Gates: 1/2/4/8 times base for 1/2/3/4 owned. Works: dice × 4 (one owned) or × 10 (both).
- Free trading of claims, cash and Clearance Passes. Receiving a mortgaged claim costs 10% interest.
- Bankruptcy: everything goes to the creditor player, or to the bank, which auctions each claim. The last player standing wins.
- Two decks of 16 with the standard mix of effect types: advance to a space, advance to the nearest gate (double toll) or works (10× a new roll), collect, pay, pay each player, collect from each player, per-building repairs, go to Quarantine, Clearance Pass, move back 3.

**Known differences (simplifications), written down so nobody mistakes them for the standard rules:**
- Building, mortgaging and offering trades happen on your own turn (or while you're raising cash), not at any moment between turns.
- When the bank runs short of buildings, the last ones go first come, first served; there is no auction for them.
- A mortgaged claim you receive is charged its 10% at once; lifting it later costs the full mortgage + 10% again (no combined "lift on receipt" option).
- If a "pay each player" card bankrupts you, your estate goes to the first player you couldn't pay.

## Economy: same curve, original numbers

Nothing is a pasted table. `src/game/economy.ts` generates every value from constants: a quadratic price curve per system with a 12% premium on each system's last moon, a base-rent rate that grows with the system index, a rent ladder of about 5×/15×/40–42×/50–52×/60–66× base (steep jump at three domes), four building-cost tiers by side, and stipend, levies, Quarantine fee and starting cash on the same scale. Starting cash is ✦1,800.

Measured against the standard game's curve, normalised by starting cash: total moon prices +2%, base rents 0%, 1–2 dome rents −3%, 3 dome rents +12.5%, 4 dome rents +10%, spire rents +11%, building costs −3%, gates and works −4% and −3%, stipend, high levy and Quarantine fee 0%. That is inside the 10–15% band. 12 of the 154 generated moon numbers coincide with a standard value by chance; the tables as a whole don't match. `test/rules.test.ts` checks the aggregate ratios stay within 15%.

## Originality

Everything a player sees, reads or hears in Moonhold was made for this game:
- **Title, theme and names:** Moonhold, a ring of moons; every space, system, deck, card, currency (glints, ✦), building (domes, spires) and token (Comet, Prism, Kestrel, Lantern, Coral, Nova) name is original.
- **Card text and rules text:** written from scratch (`src/game/cards.ts`, `src/client/help.ts`), not paraphrased from any rulebook.
- **Art:** drawn in code on a canvas: an orbit ring of beads (no square board, no coloured strips, no centre logo), original corner glyphs (rings with a chevron, a hex pod, waves, a spiral), and shape-plus-colour tokens. No images, icon fonts or third-party art.
- **Colours:** a new eight-system palette (silver, teal, violet, lime, ice, magenta, gold, onyx) in an order unlike the standard board's, with a mark on each system for colour-blind players.
- **Sound:** synthesised live with Web Audio; no audio files.
- **Fonts:** the device's own system font; nothing is bundled or loaded.

Moonhold is not affiliated with or endorsed by the maker of any other board game.
