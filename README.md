# Bankroll

A city property-trading board game for phones. 2–6 players share one device (pass-and-play), and any seat can be a bot. It runs fully offline. Built on [app_builder](https://github.com/leftbrain847/app_builder) as a `solo` app, so the same build ships as a single page, a friends link and an offline Google Play bundle.

## Run
```
npm ci
npm run dev          # local dev server
npm run build:demo   # the whole game as one self-contained page: dist/demo/page.html
npm run build:play   # offline Play bundle, checked for network code
```

## Test
```
npm run typecheck && npm test
```
CI (`.github/workflows/app.yml`, generated by app_builder) runs typecheck, tests, the build and the Play no-network check.

## How it's built

| Path | What |
| --- | --- |
| `src/game/economy.ts` | **The one economy config.** Every price, rent, building cost, salary, tax, fine and starting balance is generated from these constants. |
| `src/game/board.ts` | The 40-space board: names, colour sets, marks. |
| `src/game/cards.ts` | The News and Civic decks (16 cards each). |
| `src/game/rules.ts` | The rules engine: `apply(state, player, action)`. Pure and seeded: no clock, no `Math.random`, no DOM. |
| `src/game/ai.ts` | Bots (buying, bidding, building, raising cash, trading). Tuning in `BOT`. |
| `src/client/` | The UI: square board drawn on a canvas, action panel, property cards, synthesized sound. |
| `test/rules.test.ts` | 53 tests: one or more for every rule below. |

## Standard mechanics

Game rules are not protected by copyright, so Bankroll plays by the standard property-trading rules:

- 40-space square board: four corners (Start = collect salary, Jail = jail or just passing, Rest Stop = nothing happens, Arrested = go to Jail); 22 streets in 8 colour sets (two sets of two at the ends of sides 1 and 4, six of three); 4 subway lines mid-side; 2 utilities; 3 News + 3 Civic card spaces; 2 taxes. Same positions as the standard layout.
- 2d6 movement. Doubles roll again; a third double in one turn sends you to Jail.
- Jail: leave by paying the fine, using a Jail pass, or rolling doubles (move, no extra roll). After the third failed try, pay and move.
- Salary for passing or landing on Start.
- Buy unowned property; a declined property is auctioned to every player (the decliner too).
- A full colour set doubles base rent on its unbuilt streets, even if another street in it is mortgaged.
- 4 houses then 1 hotel, built evenly. The bank holds 32 houses and 12 hotels; when they run out nobody can build, and a hotel can only break into houses the bank has (otherwise the set is sold down at once). Buildings sell back at 50%.
- Mortgage at 50% of price; pay off at mortgage + 10%; no rent while mortgaged; sell a set's buildings before mortgaging or trading any of its streets.
- Subway lines: 1/2/4/8 times base for 1/2/3/4 owned. Utilities: dice × 4 (one owned) or × 10 (both).
- Free trading of properties, cash and Jail passes. Receiving a mortgaged property costs 10% interest.
- Bankruptcy: everything goes to the creditor player, or to the bank, which auctions each property. The last player standing wins.
- Two decks of 16 with the standard mix of effect types: advance to a space, advance to the nearest subway line (double rent) or utility (10× a new roll), collect, pay, pay each player, collect from each player, per-building repairs, go to Jail, Jail pass, move back 3.

**Known differences (simplifications):**
- Building, mortgaging and offering trades happen on your own turn (or while you're raising cash), not at any moment between turns.
- When the bank runs short of buildings, the last ones go first come, first served; there is no auction for them.
- A mortgaged property you receive is charged its 10% at once; paying it off later costs the full mortgage + 10% again.
- If a "pay each player" card bankrupts you, your estate goes to the first player you couldn't pay.

## Economy: same curve, original numbers

No price or rent table is copied. `src/game/economy.ts` generates every value from constants: a quadratic price curve per colour set with a 12% premium on each set's last street, a base-rent rate that grows along the board, a rent ladder of about 5×/15×/40–42×/50–52×/60–66× base (steep jump at three houses), four building-cost tiers by side, and salary, taxes, Jail fine and starting cash on the same scale. Starting cash is $1,750.

Prices and rents follow the same balance curve as the standard game, within 15% on aggregate ratios to starting cash (prices, base rents, hotel rents, subway price, salary, Jail fine). `test/rules.test.ts` checks this on every run. Starting cash and the fixed amounts (salary $225, taxes $210 and $105, Jail fine $55, subway rent $28) are set independently, not as a fixed multiple of the standard values.

## Commercial safety

Bankroll is built to be sold without borrowing anyone's protected material:

- **Rules only.** It reuses the standard game mechanics, which are not protected by copyright. Nothing else is taken.
- **No marks.** The classic game's name, puns on that name, its publisher's name and its mascot appear nowhere in the code, text, assets, metadata or store listing.
- **Original cards.** Both decks keep the required size and mix of effect types, but each card's situation, destination and amount is new; no card maps one-for-one onto a card from another game.
- **Original names and text.** Every street, colour set, deck, card, token and corner name is invented. "Jail", "house", "hotel", "rent", "subway" and "utility" are plain English words used for what they mean. Card text and rules text are written from scratch, not paraphrased from any rulebook or card.
- **Original look.** The board is a square track, a layout common to the whole genre. It is drawn in code with Bankroll's own palette and colour order. Colour blocks sit on the outer edge, the centre carries no logo, and the corner art is original: a coin stack, a padlock, a park bench and a siren light. Property details show rents as a grid of tiles, not a printed deed card. There is no jail-bars or police figure, parked car, train, top hat, question-mark or treasure-chest imagery.
- **Original numbers.** Prices and rents are generated by formula. They follow the same balance curve but are not the standard values.
- **No third-party assets.** There are no images, icon fonts, sound files or bundled fonts: art is drawn on a canvas, sound is synthesised live, and text uses the device's system font.

Not legal advice: before a commercial launch, have a trademark lawyer run a clearance search on the name "Bankroll" for games and apps, and review the store listing.
